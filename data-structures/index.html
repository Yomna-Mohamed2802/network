1.1 What is a Data Structure?

  • Data Structure: a way to store and organize data in the computer memory so that it can be accessed and modified efficiently.طريقة لتخزين الداتا وتنظيمها في الميموري، عشان نوصلها ونعدّلها بسرعة.
  • Data = a value or a collection of values; Structure = a method of organizing the data.الداتا = القيم، والـ Structure = طريقة ترتيبها.
  • It is the mathematical or logical representation of data in memory. Its objective: store, retrieve and update data efficiently.هدفها: نخزّن ونجيب ونحدّث الداتا بكفاءة.
  • The data elements are called members, and they can be of different types.العناصر اسمها members، وممكن تبقى من أنواع مختلفة.
  • Without data structures you can still write programs, but they may not be efficient.من غيرها البرنامج هيشتغل، بس ممكن يبقى بطيء ومش كفء.
  • Examples: stacks, queues, arrays, binary trees, linked lists, hash tables.أمثلة: stack و queue و array و tree و linked list و hash table.
  • A data structure is not a programming language; it is a set of algorithms usable in any language.الـ Data Structure مش لغة برمجة، دي أفكار نستخدمها في أي لغة.

1.2–1.3 Algorithms and the difference

  • Algorithm: a process or set of rules to perform calculations or solve a problem. It is not a complete program, just the logic, written as a flowchart or pseudo code.الـ Algorithm = خطوات حل المشكلة (اللوجيك)، مش برنامج كامل، وبيتكتب flowchart أو pseudo code.
  • Key point: choosing the best data structures and algorithms is a key to high-performance software.اختيار الـ DS والـ algorithm الصح هو سر البرنامج السريع.
  • Java offers ready structures (lists, vectors, stacks, queues, priority queues, sets, maps): the Java Collections Framework.الجاهز في Java اسمه Java Collections Framework.
  • Data structure = how data is organized ("what structure and what does it cost?"). Algorithm = a finite sequence of well-defined steps that processes data to solve a problem.الـ DS بتنظّم الداتا، والـ Algorithm بيشتغل عليها عشان يحل المشكلة.
  • Example: student IDs stored in an array (data structure) and found with linear search (algorithm). The choice of data structure strongly affects the algorithm's efficiency.مثال: الـ array هي الـ DS، والـ linear search هو الـ algorithm.

1.6–1.8 Types of data structures

  • Linear: data in sequential order; each element connected to one other element. Examples: arrays, linked lists, stacks, queues.خطية: العناصر ورا بعض، وكل عنصر متوصل بعنصر واحد.
  • Non-linear: hierarchical order; one element connected to many. Examples: trees, graphs.غير خطية: شكل هرمي، والعنصر متوصل بكذا عنصر.

1.11 Operations on data structures

  • Traversing: visiting each element to do something (e.g. average of marks: loop over the array, sum, divide by n).نلف على كل العناصر، زي حساب متوسط الدرجات.
  • Insertion: adding elements at any location. If the size is n, we can only insert n−1 data elements (as the book states).إضافة عنصر في أي مكان.
  • Deletion: removing an element from any location; deleting from an empty structure = underflow.حذف عنصر، ولو الهيكل فاضي يبقى underflow.
  • Searching: finding the location of an element: linear search or binary search.البحث: linear أو binary.
  • Sorting: arranging data in order: insertion sort, selection sort, bubble sort…الترتيب.

2.6 Core array operations

  • Traversal O(n): visit each element once (for loop when you need the index, for-each for reading).نلف على العناصر.
  • Linear search O(n): scan until found (return index) or return −1.بحث واحد واحد.
  • Insertion O(n): a full fixed array needs: (1) create a larger array, (2) copy elements, (3) insert, (4) use the new array. This is why ArrayList is useful.لو الـ array مليانة: نعمل واحدة أكبر وننسخ ونضيف.
  • Deletion O(n): shift the following elements left and clear the trailing slot.نزحزح العناصر شمال ونفضّي آخر خانة.
public int[] insertElement(int[] original, int element, int index) {
    int[] newArr = new int[original.length + 1];   // 1. bigger array
    for (int i = 0; i < index; i++)              // 2. copy before index
        newArr[i] = original[i];
    newArr[index] = element;                        // 3. insert
    for (int i = index; i < original.length; i++) // 4. shift the rest
        newArr[i + 1] = original[i];
    return newArr;
}

public void deleteAtIndex(int[] arr, int index, int currentSize) {
    for (int i = index; i < currentSize - 1; i++)
        arr[i] = arr[i + 1];          // shift left
    arr[currentSize - 1] = 0;         // clear trailing slot
}
في سطر واحد: الـ array أبسط وأسرع هيكل خطي في الوصول بالـ index، بس حجمها الثابت والزحزحة في الإضافة والحذف بيخلّوها أقل مرونة من الـ linked list والـ ArrayList.

3. The Array class (Lab 1)

  • Fields: items (private int[], its length = capacity) and count (how many elements are really stored, starts at 0).items هي التخزين، و count عدد العناصر الحقيقية.
  • Capacity vs count: capacity = items.length (number of slots); count = used slots. The next free slot is items[count]; every method works only below count.الـ capacity عدد الخانات، والـ count الخانات المليانة، وأول خانة فاضية items[count].
  • isFull: count == items.length · isEmpty: count == 0.مليانة لما count يساوي الطول، وفاضية لما count صفر.
public class Array {
    private int[] items;
    private int count;

    public Array(int size) { items = new int[size]; count = 0; }

    public int getCount()   { return count; }
    public int[] getItems() { return items; }
    public boolean isFull()  { return count == items.length; }
    public boolean isEmpty() { return count == 0; }

    public void append(int item) {
        if (isFull()) { System.out.println("Array is Full - cannot append " + item); return; }
        items[count] = item;   // first free slot
        count++;
    }

    public void traverse() {
        if (isEmpty()) { System.out.println("Array is empty"); return; }
        for (int i = 0; i < count; i++)          // to count, NOT items.length
            System.out.print(items[i] + " ");
        System.out.println();
    }

    public int linearSearch(int target) {
        for (int i = 0; i < count; i++)
            if (items[i] == target) return i;
        return -1;
    }

    public void deleteAtIndex(int index) {
        if (index < 0 || index >= count) { System.out.println("Invalid index"); return; }
        for (int i = index; i < count - 1; i++)   // stop at count - 1
            items[i] = items[i + 1];              // shift left
        items[count - 1] = 0;                     // clear trailing slot
        count--;
    }
}

// 1. add (append at the end) — O(1) thanks to tail
public void add(int data) {
    Node newNode = new Node(data);
    if (head == null) {          // empty list
        head = newNode;
        tail = newNode;
    } else {
        tail.next = newNode;     // old tail links to the new node
        tail = newNode;          // tail moves forward
    }
}

// 2. display (traverse)
public void display() {
    Node current = head;

        System.out.print(current.data + " -> ");
        current = current.next;
    }
    System.out.println("null");
}

// 3. search — linear, returns boolean
public boolean search(int key) {
    Node current = head;
    while (current != null) {
        if (current.data == key) return true;
        current = current.next;
    }
    return false;
}

// 4. delete (first match)
public void delete(int item) {
    if (head == null) return;                 // empty
    if (head.data == item) {                  // delete head
        head = head.next;
        if (head == null) tail = null;        // list became empty
        return;
    }
    Node current = head;
    while (current.next != null) {            // stop BEFORE the target
        if (current.next.data == item) {
            if (current.next == tail) tail = current;   // deleting the tail
            current.next = current.next.next;            // unlink
            return;
        }
        current = current.next;
    }
}

// 5. size — counts by walking
public int size() {
    int count = 0;
    Node current = head;
    while (current != null) { count++; current = current.next; }
    return count;
}

public void delete(int item) {
    if (head == null) return;                       // case 0: empty
    if (head.data == item) {                        // case 1/2: head
        head = head.next;
        if (head == null) tail = null; else head.prev = null;
        return;

4.5 Array-based stack (ArrayStack)

  • top is an index of the highest element. Empty stack: top = −1 (because 0 is a valid index). Push moves top up, pop moves it down.top = -1 يعني فاضية، والـ push بيطلّع top لفوق والـ pop بينزّله.
  • The book's StackOfIntegers figure uses size instead: size − 1 is the top index; empty stack size = 0.في رسمة StackOfIntegers بيستخدموا size، والـ top هو size − 1.
  • isFull: top == capacity − 1 · isEmpty: top == −1.مليانة لما top = capacity − 1.
  • Stack Overflow: push on a full stack · Stack Underflow: pop on an empty stack.Overflow = push على مليانة، Underflow = pop على فاضية.
public class ArrayStack {
    private int[] stack;
    private int top;
    private int capacity;

    public ArrayStack(int capacity) {
        this.capacity = capacity;
        stack = new int[this.capacity];
        top = -1;
    }
    public boolean isEmpty() { return top == -1; }
    public boolean isFull()  { return top == capacity - 1; }

    public void push(int item) {
        if (isFull()) { System.out.println("Stack Overflow! Cannot push " + item); return; }
        stack[++top] = item;          // increment top, then assign
        System.out.println("Pushed: " + item);
    }
    public int pop() {
        if (isEmpty()) { System.out.println("Stack Underflow! The stack is empty."); return -1; }
        return stack[top--];          // return, then move top down
    }
    public int peek() {
        if (isEmpty()) { System.out.println("Stack is empty."); return -1; }
        return stack[top];
    }
    public void display() {
        if (isEmpty()) { System.out.println("Stack is empty."); return; }
        System.out.print("Stack (top to bottom): ");
        for (int i = top; i >= 0; i--) System.out.print(stack[i] + " ");
        System.out.println();
    }
}
الفرق بين ++top و top--: في الـ push بنزوّد top الأول وبعدين نحط القيمة (pre-increment). في الـ pop بنرجّع القيمة الأول وبعدين ننزّل top (post-decrement).

public void addFirst(int data) {
    Node newNode = new Node(data);
    if (head == null) {          // empty list
        head = newNode;
        tail = newNode;
    } else {
        newNode.next = head;     // new node points to the old head

}
الـ node الجديدة تشاور على الـ head القديم، وبعدين الـ head يبقى هي. O(1).

2. Backward search in a doubly linked list

public boolean searchBackward(int key) {
    Node current = tail;               // start from the tail
    while (current != null) {
        if (current.data == key) return true;
        current = current.prev;        // move backward
    }
    return false;
}

3. insertAtPosition(int item, int pos) in a doubly linked list

public void insertAtPosition(int item, int pos) {
    if (pos < 0 || pos > size()) { System.out.println("Invalid position"); return; }
    Node newNode = new Node(item);
    if (pos == 0) {                         // at the head
        if (head == null) { head = tail = newNode; return; }
        newNode.next = head; head.prev = newNode; head = newNode; return;
    }
    if (pos == size()) {                    // at the tail
        newNode.prev = tail; tail.next = newNode; tail = newNode; return;
    }
    Node current = head;
    for (int i = 0; i < pos; i++) current = current.next;   // node now at pos
    newNode.prev = current.prev;           // link the new node in the middle
    newNode.next = current;
    current.prev.next = newNode;
    current.prev = newNode;
}
