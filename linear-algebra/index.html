1.1 What is a matrix?

  • An m × n matrix is a rectangular array of real numbers with m rows and n columns. Its size is "m by n".المصفوفة جدول أرقام: m صفوف و n أعمدة. الحجم بيتقري "m في n"، والصفوف دايماً الأول.
  • The entry in row i and column j is written aij, and we write A = [aij].العنصر aij: ‏i رقم الصف و j رقم العمود. مثلاً a23 = العنصر في الصف التاني والعمود التالت.
A = | 2  5  1 |      size 2 × 3   (2 rows, 3 columns)
    | 0 -1  4 |      a₁₂ = 5,  a₂₃ = 4,  a₂₁ = 0
خلي بالك: الحجم بيتكتب صفوف × أعمدة. مصفوفة 3 × 2 يعني 3 صفوف وعمودين، ومش زي 2 × 3.

1.2 Equality of matrices

  • A = B if and only if they have the same size and every pair of corresponding entries is equal (aij = bij).المصفوفتين يتساووا لو نفس الحجم وكل عنصر يساوي اللي في نفس مكانه.
Lecture example: find x and y
A = | x    4 |     B = | 5    4 |     A = B
    | 2    3 |         | x+y  3 |
a₁₁: x = 5
a₂₁: 2 = x + y  →  2 = 5 + y  →  y = −3
بنساوي كل عنصر باللي قصاده: أول عنصر بيدّينا x = 5، والعنصر اللي تحته 2 = x + y، نعوّض x فتطلع y = −3.

1.3 Addition, subtraction and scalar multiplication

  • Addition / subtraction: only for matrices of the same size; add (or subtract) the corresponding entries: (A + B)ij = aij + bij.الجمع والطرح لازم نفس الحجم، وبنجمع كل عنصر مع اللي قصاده.
  • Scalar multiplication: cA multiplies every entry by the number c. −A = (−1)A.الضرب في رقم: نضرب كل العناصر في الرقم ده.
Lecture examples
A = | 2  5 |    B = | 3  2 |
    |-1  0 |        | 1  4 |
A + B = | 2+3   5+2 | = | 5  7 |
        |-1+1   0+4 |   | 0  4 |
A − B = | 2−3   5−2 | = |-1  3 |
        |-1−1   0−4 |   |-2 -4 |
3A    = | 6  15 |
        |-3   0 |
كل عنصر مع اللي في نفس مكانه. والضرب في 3 بيتعمل لكل العناصر من غير استثناء.

1.5 Matrix multiplication

  • AB is defined only when the number of columns of A = number of rows of B: Am×k · Bk×n = (AB)m×n.شرط الضرب: أعمدة الأولى = صفوف التانية. والناتج: صفوف الأولى × أعمدة التانية.
  • Entry (i, j) of AB = (row i of A) · (column j of B) = ai1b1j + ai2b2j + … + aikbkj.كل عنصر في الناتج = صف من الأولى "في" عمود من التانية: نضرب أول في أول وتاني في تاني… ونجمع.
  • In general AB ≠ BA (not commutative). Sometimes BA does not even exist.الضرب مش تبديلي: AB غالباً مش زي BA، وأحياناً BA مش موجودة أصلاً.
  • Properties (Theorem 1.1.8): (AB)C = A(BC); A(B + C) = AB + AC; (B + C)A = BA + CA; α(AB) = (αA)B = A(αB); AIₙ = A and IₘA = A.التجميع والتوزيع شغالين، والـ I زي الواحد في الضرب.

1.6 Powers of a square matrix

  • For a square matrix A: A⁰ = Iₙ, A¹ = A, A² = AA, A³ = AAA, and Ak+1 = AkA.الأُس للمصفوفة المربعة بس: A² يعني A × A (ضرب مصفوفات، مش تربيع كل عنصر).
  • AmAk = Am+k and (Am)k = Amk.نفس قواعد الأُسس العادية.
Example: A² for A = [1 2; 3 4]
A² = | 1 2 | | 1 2 | = | 1+6   2+8  | = |  7  10 |
     | 3 4 | | 3 4 |   | 3+12  6+16 |   | 15  22 |   (NOT [1 4; 9 16])
فخ مشهور: A² مش إننا نربّع كل عنصر.

1.7 Transpose

  • The transpose Aᵀ of an m × n matrix is the n × m matrix whose columns are the rows of A: (Aᵀ)ij = aji.الـ transpose: الصفوف بتبقى أعمدة. مصفوفة 3 × 2 تبقى 2 × 3.
A = | 3  2 |        Aᵀ = | 3  5  0 |
    | 5  4 |   3×2       | 2  4  1 |   2×3
    | 0  1 |
Rule (Theorem 1.1.13)بالعربي
(Aᵀ)ᵀ = Aمرتين يرجّعها زي ما كانت
(A + B)ᵀ = Aᵀ + Bᵀtranspose الجمع = جمع الـ transposes
(cA)ᵀ = cAᵀالرقم يطلع برّه
(AB)ᵀ = BᵀAᵀفي الضرب الترتيب بيتعكس

        | 5  7  4 |                 | 0  7 |

  • Theorem 1.1.15: AAᵀ is always symmetric; B + Bᵀ is symmetric for any square B.AAᵀ دايماً متماثلة، و B + Bᵀ متماثلة.

2.1 Linear equations and their solutions

  • A linear equation in n variables: a₁x₁ + a₂x₂ + … + aₙxₙ = b, where the aᵢ (coefficients) and b (constant term) are fixed real numbers.المعادلة الخطية: كل متغير أُسه 1، ومفيش ضرب متغيرين في بعض، ولا جذور، ولا متغير تحت كسر.
  • Linear: 2x − 3y + z = 7. Not linear: xy = 4, x² + y = 1, √x + y = 2, 1/x = 3, sin x = 0.أمثلة على اللي مش خطي: ضرب متغيرين، أو أُس 2، أو جذر، أو المتغير في المقام، أو sin.
  • A solution is a sequence (s₁, …, sₙ) that satisfies the equation; the set of all solutions is the solution set.الحل = أرقام لما نعوّضها المعادلة تتحقق.
  • A system is a finite list of linear equations; a solution of the system satisfies all the equations at the same time.النظام = كذا معادلة، والحل لازم يحقق كلهم مع بعض.

2.2 Consistent and inconsistent systems

  • Inconsistent: no solution. Consistent: at least one solution.inconsistent = مالوش حل. consistent = ليه حل واحد على الأقل.
  • Theorem 1.2.6: every system has exactly one of: (i) no solution, (ii) exactly one solution, (iii) infinitely many solutions.أي نظام: يا مالوش حل، يا حل واحد، يا عدد لا نهائي من الحلول. مفيش حاجة تانية (مينفعش حلّين بس مثلاً).
x + y = 2,  x − y = 0     → one solution (1, 1)        two lines cross once
x + y = 2,  2x + 2y = 5   → no solution                parallel lines
x + y = 2,  2x + 2y = 4   → infinitely many (x = 2 − t, y = t)   same line
في معادلتين بمتغيرين: كل معادلة خط مستقيم. يتقاطعوا مرة = حل واحد. متوازيين = مفيش حل. نفس الخط = حلول لا نهائية.

2.3 The augmented matrix

  • The system AX = B is written as the augmented matrix [A | B]: the coefficient matrix A with the constants column B added.بنكتب النظام كمصفوفة: المعاملات، وخط، وعمود الثوابت.
 x +  y + 2z = 9          | 1  1  2 | 9 |        A = coefficient matrix
2x + 4y − 3z = 1    →     | 2  4 -3 | 1 |        X = [x y z]ᵀ
3x + 6y − 5z = 0          | 3  6 -5 | 0 |        B = [9 1 0]ᵀ

2.4 Elementary row operations (EROs)

Two systems are equivalent if they have the same solution set. Each ERO gives an equivalent system (Theorem 1.3.2):نظامين متكافئين = ليهم نفس الحلول. والعمليات دي مش بتغيّر الحلول:

TypeOperationNotationبالعربي
IInterchange two rowsRᵢ ↔ Rⱼنبدّل صفين
IIMultiply a row by a nonzero numbercRᵢ → Rᵢ (c ≠ 0)نضرب صف في رقم مش صفر
IIIAdd a multiple of another row to a rowRᵢ + cRⱼ → Rᵢنزوّد على صف مضاعف صف تاني
  • A is row-equivalent to B if B comes from A by finitely many EROs. Row-equivalence is reflexive, symmetric and transitive (an equivalence relation).لو قدرنا نوصل من A لـ B بعمليات صفوف، يبقوا row-equivalent.
  • Row-equivalent augmented matrices represent equivalent systems (Lemma 1.3.4).عشان كده بنحل على المصفوفة بدل المعادلات.
غلطة شائعة: الضرب في صفر مش مسموح (هيمسح المعادلة). وفي Type III بنغيّر الصف اللي على الشمال بس، والصف التاني بيفضل زي ما هو.

2.5 Row-echelon form (REF) and reduced row-echelon form (RREF)

REF conditions:شروط الـ REF:

  1. All zero rows are at the bottom.صفوف الأصفار تحت خالص.
  2. The first nonzero entry of every nonzero row is 1 (the leading 1 or pivot).أول عنصر مش صفر في كل صف = 1 (اسمه leading 1).
  3. Each leading 1 is to the right of the leading 1 in the row above (staircase).كل leading 1 على يمين اللي فوقه (شكل سلّم).

RREF = REF + every column that contains a leading 1 has zeros everywhere else (above and below).الـ RREF = REF + عمود كل leading 1 باقي عناصره أصفار، فوق وتحت.

REF:   | 1  3 -2 | 5 |        RREF:  | 1  0  0 | 4 |
       | 0  1  4 | 2 |               | 0  1  0 | 2 |
       | 0  0  1 | 3 |               | 0  0  1 | 3 |
NOT REF: | 0  1 | ... |   zero row above?  | 0 0 |  must be at the bottom
         | 2  1 |      leading entry 2 ≠ 1
  • Every row and every column of a REF matrix has at most one leading 1; a square matrix in REF is upper triangular; a square matrix in RREF is either Iₙ or has a row of zeros.مصفوفة مربعة REF = upper triangular. ولو RREF يا تبقى I يا فيها صف أصفار.

3.1 The strategy

  1. Write the augmented matrix [A | B].اكتبي المصفوفة الممتدة.
  2. Work column by column from the left: get a leading 1 (swap rows or divide), then make all entries below it zero with Type III operations.عمود عمود من الشمال: اعملي 1 في مكان الـ pivot، وبعدين صفّري اللي تحته.
  3. You now have REF → Gaussian elimination: solve the last equation and substitute backwards (back-substitution).لما توصلي REF: حلّي من آخر معادلة وعوّضي لفوق (ده Gauss).
  4. Or continue: make the entries above each leading 1 zero too → RREF → Gauss-Jordan: read the answer directly.أو كمّلي وصفّري فوق كمان لحد RREF وتقري الحل على طول (ده Gauss-Jordan).
نصيحة: اكتبي العملية جنب كل خطوة (زي R₂ − 2R₁ → R₂). ده جزء من الدرجة، وبيخليكي تلاقي غلطتك بسرعة.

3.4 Homogeneous systems

  • A system whose constant terms are all zero (AX = 0) is homogeneous.النظام المتجانس: كل الثوابت أصفار.
  • It is always consistent: x₁ = x₂ = … = 0 (the trivial solution) always works.ليه حل دايماً: الكل أصفار (اسمه الحل التافه trivial).
  • Theorem 1.4.7: a homogeneous system with fewer equations than variables has infinitely many solutions (non-trivial ones too).لو عدد المعادلات أقل من عدد المتغيرات، يبقى فيه حلول لا نهائية.
  • Theorem 1.4.8: more generally, any consistent system with fewer equations than variables has infinitely many solutions.وده صح لأي نظام consistent، مش المتجانس بس.
Example
x + y − z = 0
2x − y + z = 0        2 equations, 3 variables → infinitely many
| 1  1 -1 | 0 |  R₂ − 2R₁  | 1  1 -1 | 0 |  −⅓R₂  | 1 1 -1 | 0 |  R₁ − R₂  | 1 0  0 | 0 |
| 2 -1  1 | 0 |            | 0 -3  3 | 0 |         | 0 1 -1 | 0 |           | 0 1 -1 | 0 |
z = t free → y = t, x = 0  → (0, t, t)

What is the difference between Gaussian elimination and Gauss-Jordan elimination?

Gauss stops at REF and uses back-substitution; Gauss-Jordan continues to RREF (zeros above and below leading 1s) and reads the answer directly.REF ضد RREF.

How do you know from REF whether a system has no, one or infinitely many solutions?

Row [0…0|c≠0] → none; every variable has a leading 1 → one; a free variable → infinitely many.الجدول.

Define a homogeneous system. Why is it always consistent?

All constants zero; the zero vector is always a solution (trivial). Fewer equations than variables → infinitely many.التعريف + النظرية.

4.1 Invertible matrix

  • A square n × n matrix A is invertible if there is a matrix B with AB = Iₙ and BA = Iₙ. B is the inverse, written A⁻¹.المعكوس موجود للمصفوفة المربعة بس: A × A⁻¹ = I، و A⁻¹ × A = I.
  • A matrix with no inverse is noninvertible or singular. If the inverse exists it is unique (Lemma 2.1.2).اللي مالهاش معكوس اسمها singular. ولو ليها معكوس فهو واحد بس.
  • Theorem 2.1.4: for square matrices, AB = Iₙ already implies BA = Iₙ.يكفي نتأكد من جهة واحدة.
  • A matrix with a row of zeros or a column of zeros is not invertible (Lemma 2.1.3).لو فيها صف أو عمود كله أصفار يبقى مالهاش معكوس (لأن الـ det = 0).
  • Theorem 2.1.5: A is invertible ⇔ A is row-equivalent to Iₙ.المعكوس موجود لو قدرنا نوصّل A لـ I بعمليات صفوف.

4.2 The 2×2 formula

A = | a  b |     |A| = det(A) = ad − bc
    | c  d |
A is invertible ⇔ ad − bc ≠ 0, and then
A⁻¹ = 1/(ad − bc) · |  d  -b |      swap the main diagonal,
                    | -c   a |      change the signs of the other two
الطريقة: الـ det = ضرب القطر الرئيسي − ضرب القطر التاني. لو مش صفر: بدّلي عنصرين القطر الرئيسي، وغيّري إشارة الاتنين التانيين، واقسمي على الـ det.
Lecture example: A = [1 4; 2 3]

A⁻¹ = 1/(−5) · |  3  -4 |  = | -3/5   4/5 |
               | -2   1 |    |  2/5  -1/5 |
check: A·A⁻¹ = −1/5 · | 1 4 | | 3 -4 | = −1/5 · | -5  0 | = | 1 0 | = I ✓
                      | 2 3 | |-2  1 |          |  0 -5 |   | 0 1 |
بنتأكد بضرب A في المعكوس، لازم يطلع I.

4.3 The Gauss method: [A | I] → [I | A⁻¹]

  1. Write A next to the identity: [A | I].اكتبي A وجنبها I.

5.3 Cofactor expansion (3×3 and bigger)

  • det(A) = sum of (each entry of any one row × its cofactor): det(A) = aᵢ₁Cᵢ₁ + aᵢ₂Cᵢ₂ + … + aᵢₙCᵢₙ. The same works along any column (Theorem 2.3.2).نختار أي صف أو عمود، ونضرب كل عنصر في الـ cofactor بتاعه، ونجمع. كل الصفوف والأعمدة بتدّي نفس الإجابة.
  • Choose the row or column with the most zeros: their terms vanish.اختاري الصف أو العمود اللي فيه أصفار أكتر، عشان حدودها بتطير.
Lecture example: det of A = [1 −1 0; 1 0 −1; −6 2 3] along row 1
det(A) = a₁₁C₁₁ + a₁₂C₁₂ + a₁₃C₁₃
C₁₁ = + | 0 -1 | = 0·3 − (−1)·2 = 2
        | 2  3 |
C₁₂ = − | 1 -1 | = −(1·3 − (−1)(−6)) = −(3 − 6) = 3
        |-6  3 |
C₁₃ = + | 1  0 | = 1·2 − 0·(−6) = 2
        |-6  2 |
det(A) = 1·2 + (−1)·3 + 0·2 = 2 − 3 = −1
الـ cofactor الأول إشارته +، التاني −، التالت +. وفي الآخر بنضرب كل cofactor في العنصر بتاعه ونجمع. مهم: الضرب في العنصر نفسه بإشارته (a₁₂ = −1).
Lecture example: a 4×4 with a column of zeros
A = |  1 -2  3  0 |
    | -1  1  0  2 |      column 3 has only one nonzero entry (a₁₃ = 3)
    |  0  2  0  3 |
    |  3  4  0 -2 |

                                             |  0  2  3 |
                                             |  3  4 -2 |

5.4 Sarrus' rule (3×3 only)

copy the first two columns to the right, then
det = (sum of the 3 down-right diagonals) − (sum of the 3 up-right diagonals)

|  1 -1  0 |  1 -1
|  1  0 -1 |  1  0
| -6  2  3 | -6  2
down: 1·0·3 + (−1)(−1)(−6) + 0·1·2 = 0 − 6 + 0 = −6
up:   0·0·(−6) + 1·(−1)·2 + (−1)·1·3 = 0 − 2 − 3 = −5
det = −6 − (−5) = −1   ✓ same as the cofactor expansion
طريقة سريعة للـ 3×3 بس: نكرر أول عمودين على اليمين، ونجمع ضرب الأقطار النازلة، ونطرح منها ضرب الأقطار الطالعة. متنفعش مع 4×4.

5.5 Inverse with the adjoint (cofactor) formula

A⁻¹ = (1/|A|) · adj(A),     adj(A) = (cofactor matrix of A)ᵀ
Lecture example: A = [1 −1 0; 1 0 −1; −6 2 3], |A| = −1

C₂₁ = −((−1)·3 − 0·2) = 3      C₂₂ = +(1·3 − 0·(−6)) = 3       C₂₃ = −(1·2 − (−1)(−6)) = 4
C₃₁ = +((−1)(−1) − 0·0) = 1    C₃₂ = −(1·(−1) − 0·1) = 1       C₃₃ = +(1·0 − (−1)·1) = 1
cofactor matrix = | 2 3 2 |      adj(A) = (cof)ᵀ = | 2 3 1 |
                  | 3 3 4 |                        | 3 3 1 |
                  | 1 1 1 |                        | 2 4 1 |

                        | -3 -3 -1 |     same as the Gauss method ✓
                        | -2 -4 -1 |

11. A = [1 4; 2 3]. Find |A| and A⁻¹.

Show solution
|A| = 3 − 8 = −5 ;  A⁻¹ = −⅕[3 −4; −2 1] = [−3/5 4/5; 2/5 −1/5]
بدّلي القطر، وغيّري الإشارات، واقسمي على −5.

12. A = [1 −1 0; 1 0 −1; −6 2 3]. Find det(A), the cofactor matrix, adj(A) and A⁻¹.

Show solution
det(A) = −1
cof = [2 3 2; 3 3 4; 1 1 1]      adj = [2 3 1; 3 3 1; 2 4 1]
A⁻¹ = −adj = [−2 −3 −1; −3 −3 −1; −2 −4 −1]
التفاصيل في تاب Determinants (5.5).

13. Solve x − y = 4, x − z = 3, −6x + 2y + 3z = 2 using A⁻¹.

Show solution
X = A⁻¹B = [−2 −3 −1; −3 −3 −1; −2 −4 −1]·[4; 3; 2] = [−19; −23; −22]
x = −19، y = −23، z = −22.

14. Find det of A = [1 −2 3 0; −1 1 0 2; 0 2 0 3; 3 4 0 −2].

Show solution
expand along column 3: det = 3·(+1)·det[−1 1 2; 0 2 3; 3 4 −2] = 3·13 = 39
العمود التالت فيه عنصر واحد مش صفر.

15. If A and B are 3×3 with det(A) = 2 and det(B) = −3, find det(AB), det(A⁻¹), det(Aᵀ), det(2A), det(A²B⁻¹).

Show solution
det(AB) = 2·(−3) = −6        det(A⁻¹) = 1/2        det(Aᵀ) = 2
det(2A) = 2³·2 = 16          det(A²B⁻¹) = 2·2·(1/(−3)) = −4/3
طبّقي القواعد: الضرب = ضرب، والمعكوس = مقلوب، والرقم أُسه 3.

16. Without expanding, why is det [1 2 3; 2 4 6; 7 8 9] = 0?

Show solution
R₂ = 2R₁ (one row is a multiple of another) → det = 0 → not invertible
صف مضاعف صف تاني = الـ det صفر.

17. Is A = [2 6; 1 3] invertible?

Show solution
det = 2·3 − 6·1 = 0 → NOT invertible (singular)
الـ det صفر.

Matrices

size = rows × columns          A = B ⇔ same size and same entries
A ± B: same size only           cA: multiply every entry
AB: A(m×k)·B(k×n) = m×n         entry = row · column       AB ≠ BA in general
(AB)C = A(BC)   A(B+C) = AB+AC   AI = IA = A    A² = A·A (not squaring entries)
(Aᵀ)ᵀ = A   (A+B)ᵀ = Aᵀ+Bᵀ   (cA)ᵀ = cAᵀ   (AB)ᵀ = BᵀAᵀ
symmetric: A = Aᵀ     skew: A = −Aᵀ     upper triangular: zeros below the diagonal

Systems

always: no solution  OR  exactly one  OR  infinitely many
EROs:  Rᵢ ↔ Rⱼ    cRᵢ → Rᵢ (c ≠ 0)    Rᵢ + cRⱼ → Rᵢ
REF: zero rows at bottom, leading 1s, staircase      RREF: + zeros above and below leading 1s
[0 … 0 | c≠0] → no solution        free variable → infinitely many
homogeneous AX = 0: always consistent; fewer equations than variables → infinitely many

Inverse

2×2: A⁻¹ = 1/(ad−bc) · [d −b; −c a]     exists ⇔ ad − bc ≠ 0
Gauss: [A | I] → [I | A⁻¹]   (zero row on the left → no inverse)
adjoint: A⁻¹ = (1/|A|)·(cofactor matrix)ᵀ
(A⁻¹)⁻¹ = A   (AB)⁻¹ = B⁻¹A⁻¹   (Aᵀ)⁻¹ = (A⁻¹)ᵀ   (cA)⁻¹ = (1/c)A⁻¹   (Aᵏ)⁻¹ = (A⁻¹)ᵏ
AX = B → X = A⁻¹B

Determinant

2×2: ad − bc        Cᵢⱼ = (−1)^(i+j)·Mᵢⱼ      signs | + − + / − + − / + − + |
expand along the row/column with most zeros       Sarrus: 3×3 only
zero row/column → 0   equal or proportional rows → 0   triangular → product of the diagonal
swap rows → −det   cRᵢ → c·det   Rᵢ + cRⱼ → same det
det(AB) = det A·det B   det(Aᵀ) = det A   det(A⁻¹) = 1/det A   det(cA) = cⁿ det A
A invertible ⇔ det A ≠ 0 ⇔ AX = B has a unique solution
آخر نصيحة: اكتبي حجم كل مصفوفة، وكل عملية صفوف، وكل إشارة cofactor. وفي الآخر اتأكدي: A·A⁻¹ = I أو عوّضي الحل في المعادلات.
