Networking Fundamentals

Terms, devices, why we network, applications, characteristics, topologies, network types.

1.1–1.2 Basic definitions

  • Network: a set of devices (nodes) connected by communication links.الشبكة = مجموعة أجهزة (اسمها nodes) متوصلة ببعض بوصلات اتصال.
  • Computer network: a collection of autonomous computers interconnected by a single technology. Two computers are interconnected if they can exchange information.شبكة الكمبيوتر = كمبيوترات مستقلة متوصلة بتكنولوجيا واحدة. أي جهازين يعتبروا متوصلين لو يقدروا يتبادلوا معلومات.
  • Node: any device (computer, printer…) that can send and/or receive data on a network.الـ Node = أي جهاز يقدر يبعت أو يستقبل داتا على الشبكة.
  • Medium: the physical path that carries data: copper twisted-pair, fiber optic, or wireless (air/radio).الوسط = الطريق اللي الداتا بتمشي فيه: كابل نحاس، فايبر، أو وايرلس في الهوا.
  • Protocol: standardized rules that govern how data is exchanged (e.g. TCP/IP).البروتوكول = قواعد متفق عليها بتنظم إزاي الأجهزة تتبادل الداتا، زي "لغة مشتركة".
  • NOS (Network Operating System): OS on servers that manages network resources: Windows Server 2019/2022, Ubuntu Server, Red Hat, macOS Server.نظام تشغيل مخصوص للسيرفرات بيدير موارد الشبكة، زي Windows Server و Linux.
  • Client: requests data or services.العميل = الجهاز اللي بيطلب الخدمة.
  • Server: provides data, resources or services to clients.السيرفر = الجهاز القوي اللي بيقدّم الخدمة للعملاء.
  • Connectivity device: hardware that connects network segments (switches, routers, access points).أجهزة التوصيل = اللي بتربط أجزاء الشبكة ببعض، زي السويتش والراوتر والأكسس بوينت.
  • LAN: small area (room, building, campus).شبكة في مكان صغير: أوضة، مبنى، أو حرم جامعة.
  • WAN: connects LANs over a large area (leased lines, fiber, satellite).شبكة بتربط شبكات LAN على مساحة كبيرة جدًا.
  • Physical topology: the actual layout of the hardware.الشكل الحقيقي لتوصيل الكابلات والأجهزة على الأرض.
  • Logical topology: the path data actually takes, regardless of the physical layout.الطريق اللي الداتا ماشية فيه فعلًا، بغض النظر عن شكل الكابلات.

1.3 Networking devices

  • End-user devices: computers, printers, scanners, smartphones, tablets: give services directly to the user.أجهزة المستخدم: اللي بنستخدمها بإيدينا، زي الكمبيوتر والموبايل والطابعة.
  • Network devices: connect end-user devices together: switches, routers, wireless access points (WAPs), firewalls.أجهزة الشبكة: اللي بتوصّل أجهزة المستخدمين ببعض، زي السويتش والراوتر والفايروول.
  • NIC (Network Interface Card): hardware that connects a computer to a network (LAN).كارت الشبكة: القطعة اللي جوه الكمبيوتر وبتوصّله بالشبكة.
  • Hub: connects a group of hosts.الهب بيوصّل مجموعة أجهزة، وبيبعت الداتا لكلهم من غير ما يفرّق.
  • Switch: connects end devices inside the same network (LAN). Looks at the destination MAC address and sends data only to the intended device ("smart traffic controller").السويتش بيوصّل الأجهزة جوه نفس الشبكة، وبيبص على الـ MAC بتاع المستقبِل ويبعت الداتا ليه هو بس، زي عسكري مرور ذكي.
  • Router: connects different networks (home LAN ↔ Internet, branch ↔ HQ). Looks at the destination IP address and picks the best path ("post office").الراوتر بيوصّل شبكات مختلفة ببعض، وبيبص على الـ IP ويختار أحسن طريق، زي مكتب البريد.

1.4–1.5 Why network? Applications

  • Main goal: increase productivity by linking computers.الهدف الأساسي من الشبكة: نزوّد الإنتاجية بإننا نربط الأجهزة ببعض.
  • Corporate networks are split into user groups by employee role.شبكات الشركات بتتقسم مجموعات حسب وظيفة الموظف.
  • Remote sites (branches, home offices, mobile workers) connect to the corporate LAN through a WAN service.الفروع واللي شغالين من البيت بيتوصلوا بشبكة الشركة عن طريق WAN.

Shared resources

  • Data & applications: email, shared databases, cloud software.مشاركة الداتا والبرامج، زي الإيميل وقواعد البيانات.
  • Resources: input/output devices: cameras, scanners, printers.مشاركة الأجهزة، زي طابعة واحدة للمكتب كله.
  • Network storage: DAS (directly attached), NAS (Network Attached Storage), SAN (Storage Area Network).مشاركة أماكن التخزين: DAS متوصل بالجهاز مباشرة، NAS على الشبكة، SAN شبكة تخزين كاملة.
  • Backup devices: back up data from many computers for recovery and business continuity.أجهزة باك أب بتاخد نسخة من داتا أجهزة كتير عشان لو حصلت مشكلة نرجّعها والشغل يكمّل.

Network user applications

  • E-mail · Web browsers · Instant messaging & collaboration (Teams, Slack, Zoom) · Databases.برامج المستخدم اللي بتشتغل على الشبكة: الإيميل، المتصفح، الشات والاجتماعات، وقواعد البيانات.

1.7 Physical topologies

  • Bus: all devices on one central cable (backbone) with terminators at both ends. Largely obsolete.كل الأجهزة على كابل واحد في النص، وفي آخره من الناحيتين terminators. مبقتش بتستخدم.
    • Pros: cheap, less cable than star.مميزات: رخيصة وكابلها أقل من الـ Star.
    • Cons: one break kills the whole network; hard to find the break; slower as devices are added.عيوب: لو الكابل اتقطع الشبكة كلها تقع، وصعب نعرف القطع فين، وكل ما نزوّد أجهزة تبطأ.
  • Ring: closed loop, data in one direction (or both in dual ring). Legacy FDDI.الأجهزة في دايرة مقفولة والداتا ماشية في اتجاه واحد (أو الاتجاهين في الـ dual ring).
    • Pros: orderly, no collisions.مميزات: الداتا ماشية بنظام ومفيش تصادم.
    • Cons: one failure breaks the ring (unless dual ring); adding a device needs a shutdown.عيوب: جهاز أو كابل واحد يبوظ الدايرة كلها، وعشان نضيف جهاز لازم نوقف الشبكة.
  • Star: all devices to a central switch/hub. Most common in modern LANs.كل الأجهزة متوصلة بجهاز في النص (سويتش أو هب). دي الأشهر النهارده.
    • Pros: easy to install, troubleshoot and add devices; one cable break affects one PC.مميزات: سهلة في التركيب والصيانة والإضافة، ولو كابل اتقطع جهاز واحد بس اللي يتأثر.
    • Cons: central switch fails → whole network down; more cable than bus.عيوب: لو السويتش اللي في النص وقع الكل يقع، وكابلها أكتر من الـ Bus.
  • Mesh: Full = every device to every device. Partial = some devices to several others (WANs, Internet backbone).Full: كل جهاز متوصل بكل جهاز. Partial: بعض الأجهزة بس متوصلة بأكتر من جهاز.
    • Pros: most reliable, fault tolerant, no collisions, secure.مميزات: أكتر واحدة يُعتمد عليها، لو وصلة وقعت الداتا تاخد طريق تاني، ومفيش تصادم.
    • Cons: most expensive, lots of cable and ports, hard to set up.عيوب: الأغلى، كابلات وبورتات كتير جدًا، وصعبة في التركيب.

1.8 Types of networks

Classified by size, area covered and physical architecture. The three primary types are LAN, MAN, WAN.الشبكات بتتقسم حسب الحجم والمساحة. الأنواع الأساسية تلاتة: LAN و MAN و WAN.

  • LAN: room, building or campus. Uses CAT 5e, CAT 6 or fiber (coax obsolete); minimal errors and noise; 1–10 Gbps+ (10–100 Mbps is now slow). Example: school lab, home Wi-Fi.شبكة محلية في مكان صغير، كابلاتها CAT 5e أو CAT 6 أو فايبر، أخطاؤها قليلة لأن المسافة قصيرة، وسرعتها من 1 لـ 10 جيجا. مثال: معمل الكلية.
  • MAN: 5–50 km (a city); connects several LANs; owned by one organization (city government) or a big ISP; slower than LAN. Example: branches across a city, city-wide Wi-Fi.شبكة على مستوى مدينة (5 لـ 50 كم)، بتربط كذا LAN، ومملوكة لجهة واحدة أو شركة إنترنت كبيرة، وأبطأ من الـ LAN.
  • WAN: country or world; contains many LANs and MANs; was satellite and microwave, now fiber backbone, MPLS, 4G/5G; speed depends on ISP, technology, location. Best example: the Internet.شبكة على مستوى دولة أو العالم كله وفيها LANs و MANs كتير. أحسن مثال: الإنترنت.
  • WLAN: a LAN over radio waves (Wi-Fi); Wi-Fi 6/7 is close to wired speeds.LAN بس من غير كابلات، شغالة بالواي فاي.
  • PAN: personal, about 10 m; Bluetooth, NFC, USB. Example: phone + earbuds, laptop + wireless mouse.شبكة شخصية في حدود 10 متر، زي الموبايل مع السماعة البلوتوث.
  • SAN: high-speed network from servers to storage; Fibre Channel or iSCSI, block-level; looks to the server like a local drive; used for backups, disaster recovery, mirror copies.شبكة سريعة جدًا بتوصّل السيرفرات بأجهزة التخزين، والسيرفر بيشوفها كأنها هارد جواه. بتستخدم للباك أب واسترجاع الداتا وقت الكوارث.

Expected essay questions

Compare between switch and router.

Switch connects devices inside the same LAN and forwards frames using the destination MAC address, sending data only to the intended device. Router connects different networks (e.g. LAN to Internet) and forwards packets using the destination IP address, choosing the best path. Switch works at Layer 2, router at Layer 3.السويتش جوه الشبكة الواحدة بالـ MAC في الطبقة 2، والراوتر بين الشبكات بالـ IP في الطبقة 3 وبيختار أحسن طريق.

List the characteristics of a network.

Speed, cost, security, availability, scalability, reliability, topology (one line of definition for each).اكتبي السبع خصائص وتحت كل واحدة سطر تعريف من الجدول.

Explain the three categories of network applications.

Batch (FTP, TFTP: starts and finishes alone), interactive (database queries: user waits, response depends on the server), real-time (VoIP, video: time critical, needs bandwidth and QoS).Batch تشتغل لوحدها، Interactive المستخدم يستنى الرد، Real-time الوقت فيها حرج.

Seven layers, encapsulation, unicast/broadcast/multicast, collision and broadcast domains, TCP/IP model.

موديل OSI: السبع طبقات، التغليف، أنواع الإرسال، الـ domains، وموديل TCP/IP.

2.1 Why OSI?

  • Early networks were chaotic: each vendor had a proprietary solution that did not work with others.في الأول كل شركة كانت عاملة حل خاص بيها ومش بيشتغل مع أجهزة الشركات التانية.
  • The OSI (Open Systems Interconnection) model, created by ISO, is a conceptual 7-layer framework describing how data moves across a network.عشان كده ISO عملت موديل OSI: إطار نظري من 7 طبقات بيشرح الداتا بتتنقل إزاي.
  • Divides communication into seven functional layers.بيقسم عملية الاتصال لسبع طبقات.
  • Gives each layer specific responsibilities.كل طبقة ليها شغلانة محددة.
  • Promotes compatibility between systems.بيخلي الأجهزة من شركات مختلفة تشتغل مع بعض.
  • Simplifies design, implementation and troubleshooting.بيسهّل التصميم والتنفيذ واكتشاف الأعطال.

Layer 7 · Application

  • Highest layer, closest to the user.أعلى طبقة وأقرب واحدة للمستخدم.
  • Provides network services to applications (browsers, email clients, file transfer tools).بتقدّم خدمات الشبكة للبرامج زي المتصفح والإيميل.
  • It is the window between the user and the network.هي الشباك اللي المستخدم بيطل منه على الشبكة.
  • It is the protocols apps use, not the app itself: Chrome is not the Application layer, HTTP is.الطبقة دي هي البروتوكولات مش البرنامج نفسه: Chrome مش هو الطبقة، الـ HTTP هو الطبقة.

Layer 6 · Presentation ("translator")

  • Makes sure data is in a format both devices understand. Handles format, encryption, compression.المترجم: بيخلي الداتا بشكل الجهازين يفهموه، وشغله: التنسيق والتشفير والضغط.
  • Translation: converts formats (ASCII ↔ EBCDIC, Windows ↔ Linux/Mac).الترجمة: يحوّل بين صيغ الداتا المختلفة، زي ملف من ويندوز يتفتح صح على ماك.
  • Character encoding: ASCII, Unicode/UTF-8 (all languages), EBCDIC (old IBM). "A" = 65 in ASCII.ترميز الحروف: كل حرف ليه رقم، زي A = 65 في ASCII، و UTF-8 بيدعم كل اللغات.
  • Compression: smaller data, saves bandwidth (ZIP, JPEG, MP3); receiver decompresses.الضغط: يصغّر حجم الداتا عشان توصل أسرع، والمستقبِل يفكّها.
  • Encryption / decryption: protects data in transit (HTTPS, SSL/TLS, VPN).التشفير: يشفّر الداتا قبل ما تتبعت ويفكّها عند الوصول عشان محدش يسرقها.
  • Formats: Text ASCII/Unicode/UTF-8/EBCDIC · Images JPEG/PNG/GIF/BMP · Audio MP3/WAV/AAC · Video MP4/AVI/MKV · Compression ZIP/RAR/GZIP.أمثلة للصيغ اللي الطبقة دي بتتعامل معاها: نصوص، صور، صوت، فيديو، وملفات مضغوطة.
  • Other: MIME (email attachment encoding), XDR (data representation for RPC).MIME لمرفقات الإيميل، و XDR لتمثيل الداتا في RPC.

Layer 5 · Session ("dialogue manager")

  • Opens, manages and closes communication sessions between two devices. A session lasts from login to logout.مدير الحوار: بيفتح الجلسة بين جهازين ويديرها ويقفلها، زي من وقت ما تعملي login لحد logout.
  • Lifecycle: Establishment (open, set rules) → Maintenance (keep active, manage flow) → Termination (close cleanly).دورة الجلسة: فتح وتحديد القواعد ← استمرار ← قفل نضيف. زي المكالمة: تتصلي، تتكلمي، تقفلي.
  • Authentication & security: verifies both parties before the session (username + password).التحقق: يتأكد من هوية الطرفين قبل ما الجلسة تبدأ.

2.11 Types of transmission

They answer one question: who is supposed to receive this data?أنواع الإرسال بتجاوب على سؤال واحد: مين المفروض يستقبل الداتا دي؟

  • Broadcast (one-to-all): to every device on the local network, using 255.255.255.255 (IPv4) or FF:FF:FF:FF:FF:FF (MAC); everyone must process it. Analogy: megaphone. Example: ARP request, DHCP discovery.من واحد لكل اللي في الشبكة المحلية، زي ميكروفون في أوضة مليانة ناس.

2.12 Collision & broadcast domains

  • Collision domain: part of a network where collisions can happen (two devices send at the same time on a shared segment; both must resend, which lowers efficiency).المنطقة اللي ممكن يحصل فيها تصادم لو جهازين بعتوا في نفس اللحظة، وساعتها الاتنين يعيدوا الإرسال.
  • All hub ports = one collision domain. Each port of a bridge, switch or router = a separate collision domain.الهب كله collision domain واحد، لكن كل بورت في السويتش أو الراوتر domain لوحده.
  • Broadcast domain: the area a broadcast reaches (all devices reachable at layer 2 by broadcast).المنطقة اللي رسالة البرودكاست بتوصلها.
  • All hub or switch ports = one broadcast domain. Each router port = separate broadcast domain; routers do not forward broadcasts.الهب والسويتش ما بيقسموش البرودكاست، الراوتر بس اللي بيقسم لأنه مبيعدّيش البرودكاست.
طريقة العدّ:
• Collision: كل port في سويتش أو راوتر = 1، والهب باللي متوصل بيه = 1 بس.
• Broadcast: عدّي الراوترات بس: كل interface في الراوتر = 1.
مثال الكتاب (Hub بـ3 PCs + Switch بـ2 PCs + Router بـ2 PCs): 6 collision domains و 3 broadcast domains.

4.1 Layer 2 switching

  • Switching = transferring data between devices using switches, mainly at the Data Link layer, forwarding frames by MAC address.السويتشنج = نقل الداتا بين الأجهزة بالسويتش في الطبقة 2، والفريمات بتتوجه بالـ MAC.
  • A switch connects multiple devices within a network.السويتش بيوصّل أجهزة كتير في نفس الشبكة.
  • It reduces interference by sending data only to the intended device.بيقلل الزحمة لأنه بيبعت للجهاز المقصود بس.
  • It forwards frames to the correct port using MAC addresses.بيبعت الفريم للبورت الصح عن طريق الـ MAC.
  • For outside networks, it forwards data to a router.لو الداتا رايحة بره الشبكة بيبعتها للراوتر.

How the MAC address table is built (book example, ports E0–E3)

  1. The table starts empty.في الأول الجدول فاضي.
  2. A sends to C → switch learns A's source MAC on E0; C unknown → frame flooded to all ports except E0.A بعت لـ C: السويتش سجّل A على E0، ولأنه ميعرفش C بعت الفريم لكل البورتات ما عدا E0.
  3. D sends to C → switch learns D on E3; still floods to all ports except E3.D بعت لـ C: اتسجل D على E3، ولسه بيعمل flooding.
  4. After all stations send, the table is complete: E0 A, E1 C, E2 B, E3 D.بعد ما الكل يبعت، الجدول يتملي.
  5. A sends to C again → destination known → sent only to E1, not flooded.لما A يبعت لـ C تاني، السويتش عارف مكانه فيبعت لـ E1 بس.
الخلاصة: السويتش بيتعلم من الـ source MAC، وبيقرر يبعت فين من الـ destination MAC.

4.2 Loop avoidance

  • Redundant links between switches give backup paths, but create switching loops.لما نوصّل السويتشات بأكتر من كابل للاحتياط، ممكن يحصل لوب والداتا تلف في دواير.
  • Layer 2 frames have no TTL field, so a frame can circulate forever.الفريم ملوش TTL (عمر) فيفضل يلف للأبد.
  • Broadcast storms: broadcasts flooded endlessly, eat all bandwidth, can crash the network.عاصفة برودكاست: البرودكاست يتكرر لحد ما ياكل الشبكة كلها وتقع.
  • MAC table instability: same frame on several ports, the table keeps changing, wrong forwarding.جدول الـ MAC يفضل يتغير لأن نفس الفريم جاي من كذا بورت، فالسويتش يبعت غلط.
  • Duplicate frame delivery: the same frame arrives several times.نفس الفريم يوصل أكتر من مرة ويلخبط الطبقات اللي فوق.

4.3 Spanning Tree Protocol (STP) · IEEE 802.1D

  • Prevents loops while keeping redundancy by putting redundant paths in a blocking state.STP بيمنع اللوب وفي نفس الوقت بيسيب الكابلات الاحتياطي، بس بيقفلها منطقيًا.

  • Blocked links stay physically connected; if the main link fails, STP activates the backup automatically.لو الكابل الأساسي وقع، STP بيفتح الاحتياطي لوحده.

The 3 types of subnetting questions

Type 1: given the IP and asked for a number of subnets

Example: "divide it into 10 subnets", or into 2 or 3.النوع الأول: يديكي الـ IP والـ subnet mask، ويقولك عايز 10 subnets مثلًا، أو قسّميها لـ 2 أو 3.

  1. Find n (bits to borrow): the smallest n where 2n ≥ the subnets needed (no −2 here; −2 is only for hosts).هاتي n: أصغر رقم يخلي 2 أس n أكبر من أو يساوي عدد الـ subnets المطلوب، ومن غير −2 هنا. الـ −2 للـ hosts بس.
  2. New prefix = old prefix + n.الـ prefix الجديد = القديم + n.
  3. From the prefix table: block size and mask.من جدول الـ prefix هاتي الـ block والـ mask.
  4. List the subnets: start from 0 and add the block each time, in the octet that changes.اكتبي الشبكات: ابدأي من 0 وزوّدي الـ block كل مرة، في الـ octet اللي بيتغير.
  5. For each subnet: network = the start, first host = network + 1, broadcast = next network − 1, last host = broadcast − 1.لكل شبكة: أول عنوان network، وبعده أول host، وقبل الشبكة اللي بعدها بواحد broadcast، وقبله آخر host.

Type 2: not asked for subnets, asked for hosts

Example: "each network needs 20 hosts" or "30 hosts".النوع التاني: مش بيقولك عايز كام subnet، بيقولك محتاج 20 أو 30 host مثلًا.

  1. Find h (host bits): the smallest h where 2h − 2 ≥ the hosts needed.هاتي h: أصغر رقم يخلي 2 أس h ناقص 2 أكبر من أو يساوي عدد الأجهزة.
  2. Prefix = 32 − h. Example: 40 hosts → 26 = 64 → 32 − 6 = /26.الـ prefix = 32 ناقص h. مثال النوتة: 40 جهاز ← 2^6 = 64 ← 32 − 6 = /26.
  3. Block = 2h. Then list the subnets as in Type 1. With different sizes (VLSM), start with the biggest.الـ block = 2^h، وبعدين اكتبي الشبكات زي النوع الأول. ولو الأحجام مختلفة (VLSM) ابدأي بالأكبر.

Type 3: the subnetting is already done

You get one IP address with its prefix and must find the network, first IP, last IP and broadcast.النوع التالت: الـ subnetting معمول أصلًا، وهيديكي IP واحد، ومطلوب منك الـ network وأول IP وآخر IP والـ broadcast.

  1. From the prefix: which octet changes, and the block size.من الـ prefix اعرفي أنهي octet بيتغير، والـ block كام.
  2. Count in that octet by the block: 0, block, 2×block… until you pass the IP's number.عدّي في الـ octet ده بالـ block لحد ما تعدّي رقم الـ IP.
  3. See where the number falls: the multiple just below it (or equal) is the network address. Octets after it become 0.شوفي الرقم واقع بين أنهي شبكتين: اللي تحته على طول هو الـ network address، والـ octets اللي بعده تبقى أصفار.
  4. First host = network + 1. Broadcast = next multiple − 1 (octets after it become 255). Last host = broadcast − 1.أول host = الـ network + 1. الـ broadcast = الشبكة اللي بعدها − 1، والـ octets اللي بعده تبقى 255. آخر host = الـ broadcast − 1.
متأكد منها: القانون الصح هو قانون الكتاب.
• عدد الـ subnets = 2n، من غير طرح.
• عدد الـ hosts = 2h − 2، والـ 2 دول الـ network address والـ broadcast بتوع كل شبكة.
الـ −2 اللي في النوتة مكانها الـ hosts بس. زمان، في RFC 950 سنة 1985، كانوا بيشيلوا أول subnet (subnet zero) وآخر subnet (all-ones)، فكان عدد الشبكات 2n − 2. القاعدة دي اتلغت في RFC 1878 سنة 1995، وسيسكو بقت بتستخدم subnet zero تلقائي من IOS 12.0. عشان كده الكتاب في مثال الـ 4 subnets استلف 2 bits بس.
Subnets = 2n · Usable hosts = 2h − 2
